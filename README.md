# CLauncher by Cloud

Бесплатный лаунчер Minecraft для Windows.

## Возможности

- Установка отдельных сборок Vanilla, Fabric, Forge, NeoForge и Quilt с доступными для них версиями игры.
- Выбор версий Minecraft, включая снапшоты для Vanilla.
- Настройки Java, памяти и запуска для каждой сборки.
- Управление локальными модами и ярлыки сборок с индивидуальными значками.
- Русский, украинский и английский интерфейс; несколько тем оформления.

## Скачать

**Проверенная публичная сборка пока готовится.** Когда она будет опубликована, установщик появится в [Releases](https://github.com/dev-cloud-ai/CLauncher-Releases/releases).

Вход Microsoft реализован по коду устройства, но проверка реального входа и настройка доступа Minecraft API ещё не завершены.

Этот репозиторий предназначен для готовых сборок, описаний изменений и сообщений об ошибках. Исходный код хранится отдельно в приватном репозитории.

## Сообщить об ошибке

Откройте Issue: укажите версию Windows, версию игры и загрузчик, шаги воспроизведения и текст ошибки. Не прикладывайте токены, пароли или файлы учётных записей.

CLauncher — независимый проект, не связанный с Mojang или Microsoft.
